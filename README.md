A short poem about agency — the power to ask and to be given, and the
agency that passes between a person and the machine that acts for them.
The program (`main.ts`, Node 22, standard library only) writes the poem
to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
